# My Timetable

A small static website. Load the college timetable Excel sheet, pick your **year** and type your **group number**, and you get your own **day-wise timetable**.

- Classes come in time order for each day. The page shows free gaps between classes, highlights today, and has a week-grid view.
- **Shared classes:** when several groups have the same class at the same time, each group's card says *"Together with G2, G3, …"*.
- Two classes at the same time for one group appear side by side.
- The Excel file is read entirely in the browser. Nothing gets uploaded to a server.
- Your last choice is remembered. The URL (`#year=2&cat=CSE&group=C203`) can be shared.

## Run it

Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify…).
Then drop the Excel file on the page.

**To publish one timetable for everyone:** put the file at `data/timetable.xlsx` (or `.xls` / `.csv`).
The site loads it automatically, so visitors only pick their year and group.
(This needs the site to be served over http(s). It doesn't work from `file://`.)

## Supported sheet layouts

Each sheet is detected automatically. You can see what was detected under **"How the sheet was read"** at the bottom of the page.

**1. List layout: one row per class**

| Year | Branch | Group | Day | Start Time | End Time | Subject Code | Subject | Type | Faculty | Room |
|------|--------|-------|-----|-----------|----------|--------------|---------|------|---------|------|
| 2 | CSE | C201-C205 | Monday | 10:00 | 11:00 | CSE204 | Computer Networks | L | Prof. Sen | LT-104 |
| 2 | CSE | C203 | Monday | 12:00 | 13:00 | CSE205 | DBMS | T | Prof. Nair | TR-4 |

- Header names are matched loosely: *Batch/Section* for Group, *Branch/Department* for Category, *Timing/Slot* for Time, *Venue/Hall* for Room, and so on.
- A single `Time` column like `9:00-9:50` or `9 - 10 AM` also works.
- The group cell can list several groups: `G1, G2`, `G1-G5`, `G1 & G3`, or `All`.
- If the same class is repeated on separate rows (one per group), those rows are also recognised as a shared class.
- Blank Day/Time/Year cells under a heading are filled in from the row above.
- If there is no Year column, the year is taken from the sheet name (e.g. `2nd Year`).

**2. Grid layout: one column per group**

| Day | Time | G1 | G2 | G3 |
|-----|------|----|----|----|
| Monday | 9:00-9:50 | Maths (L) *(merged across G1–G3)* | | |

Merged cells across group columns mean the groups share that class.

A sample with 120 groups is in `samples/sample-timetable.xlsx`. It was generated by `tools/make-sample.js`.
